# Archived results

The outputs of the run behind the manuscript, so a reader can check any reported value
without re-running the pipeline.

| Path | Contents |
|---|---|
| `canonical_results.csv` | one row per (`run_id`, metric): headline run, rolling origins, contamination sweep, split comparison, clock ablation. 8,188 rows, 628 `run_id`s |
| `manifest.json` | library versions, seed, grids and caps of the run |
| `manifest_clock_ablation.json` | the same for the clock-ablation run |
| `table_*.csv` | the analyses written by their own cells: aggregation schemes, PaySim ablation, label efficiency, bootstrap intervals, operational measurements, hyperparameter and subsampling sensitivity; the `table_clock_*.csv` files are written by `../scripts/clock_ablation/` |
| `phase0/` | the validation-selected hyperparameter configurations with their tie sets, the paired bootstrap comparisons of the ensemble against each member and the per-fold rolling-origin values |
| `manuscript_tables/` | the same tables in the layout used in the paper, rebuilt by `../scripts/make_manuscript_tables.py` |
| `figures/` | the figures as published; `figure1_data_access.pdf` is Figure 1, drawn by `../scripts/figure1_data_access.py` |
| `R2/` | the outputs of `../notebooks/revision_R2_reviewer1.ipynb`, the analyses added in the second revision (see the main README) |

Not included: `test_scores.npz` (83 MB of raw score vectors), regenerated by cell 13 of the
notebook and archived as a separate file in Zenodo version 1.2.0
(https://doi.org/10.5281/zenodo.22847968); and the `scores_*.npz` files of `R2/units/`
(785 MB), regenerated by the second-revision notebook.

To regenerate everything, set the two dataset paths and run the notebook top to bottom;
outputs are written to `revision_v2/` and can be diffed against this directory.
